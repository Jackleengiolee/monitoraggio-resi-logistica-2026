# Monitoraggio Resi e Logistica 2026

Progetto di analisi e monitoraggio dei resi logistici sviluppato con Microsoft Excel e Google BigQuery.

## Obiettivi
- Monitorare il flusso dei resi
- Analizzare le cause delle restituzioni
- Misurare i principali KPI logistici
- Supportare il miglioramento dei processi operativi

## KPI Monitorati
- Valore totale dei resi
- Valore medio per reso
- Tasso di reimmissione in stock
- Analisi per categoria prodotto
- Trend dei resi nel tempo

## Strumenti Utilizzati
- Microsoft Excel
- Google BigQuery
- SQL
- GitHub

## Contenuto del Progetto
Il repository contiene una dashboard Excel con dati simulati e indicatori di performance utilizzati per l'analisi dei resi e il monitoraggio delle attività logistiche.
